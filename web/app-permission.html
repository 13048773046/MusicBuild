流萤音乐应用权限清单

更新日期：2026年10月22日

为向您提供音乐播放、社交互动、消息推送等服务，本应用（含 iOS 与 Android 版本）会在您使用相应功能时申请下列系统权限。我们遵循"最小必要"原则，仅在功能需要时申请权限，您可以随时在系统设置中开启或关闭各项权限。

一、权限明细

权限 对应系统权限标识 用途与说明
网络 Android：INTERNET / ACCESS_NETWORK_STATE
iOS：蜂窝数据 / Wi-Fi		 访问网络，实现在线播放、搜索、加载封面与歌词、上传内容等核心功能。拒绝后将无法使用本应用。
通知 Android：POST_NOTIFICATIONS
iOS：通知（远程推送）		 接收互动通知（点赞、评论、关注、粉丝）与官方通知提醒、后台播放媒体控制。可在系统设置中关闭，关闭后不影响播放功能。
定位 Android：ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION
iOS：使用期间定位（NSLocationWhenInUseUsageDescription）		 仅在您使用"天气 × 时段"场景推荐时获取当前位置，用于提供应景的推荐内容。仅在使用期间获取，可随时关闭；关闭后该功能显示"仅时段"兜底，不影响其他服务。
相册 Android：系统相册选择器
iOS：系统照片选择器		 在您主动上传头像、个人主页背景图、评论配图时读取所选图片。仅在您主动选择时访问，不会自动读取相册内容。
相机 Android：CAMERA（拍摄头像时）
iOS：未申请		 Android 端在您主动选择"拍摄头像"时调用相机；iOS 端不申请相机权限。仅在您主动拍摄时使用。
后台播放 Android：FOREGROUND_SERVICE / FOREGROUND_SERVICE_MEDIA_PLAYBACK / WAKE_LOCK / MODIFY_AUDIO_SETTINGS
iOS：后台音频模式（UIBackgroundModes）		 锁屏或切至后台时继续播放音乐、保持音频焦点与系统媒体控制。系统自动使用，无需授权。

二、其他说明

  • 本地存储：本应用不申请本地存储（读写外部存储）权限。歌曲缓存、下载内容与个人数据均保存在应用私有目录（系统自动管理，卸载即清除）；选择相册图片时使用系统提供的安全相册选择器，仅返回您选中的图片，不读取整个存储空间。
  • 本应用遵循"最小必要"原则：未申请麦克风、通讯录、短信、日历等与音乐服务无关的权限。
  • Android 版另有部分系统自动管理的声明权限（如 VIBRATE、SYSTEM_ALERT_WINDOW、WRITE_SETTINGS、RECEIVE_USER_PRESENT），其中悬浮窗等权限已声明但当前版本未实际使用。
  • 您在系统设置中关闭某项权限后，仅影响对应功能（如关闭定位则天气场景推荐不可用），其余功能不受影响；重新开启即可恢复。
  • 我们不会在您不知情的情况下申请或使用权限，也不会将权限用于清单之外的目的。

三、权限管理方式

  • Android：系统设置 → 应用管理 → 流萤音乐 → 权限，可逐项开启或关闭。
  • iOS：系统设置 → 流萤音乐 → 权限，可逐项开启或关闭。

如您对本清单有任何疑问，请通过应用内"我的 - 设置 - 关于 APP"中的联系方式与我们联系。
